# Zauvariebyz

A digital storefront and product catalog developed for an independent handmade bouquet business.

## Overview

Zauvarie is a web-based catalog created to present handmade bouquet products in a structured and accessible digital storefront.

The website provides customers with a practical way to browse available products and explore different bouquet options.

## Features

- Digital bouquet catalog
- Product listings
- Product images
- Product descriptions
- Product pricing
- Stock information
- Product categories
- Shopping experience

## Technologies

- HTML
- CSS
- JavaScript
